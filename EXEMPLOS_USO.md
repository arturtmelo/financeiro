Este guia mostra como usar o sistema no dia a dia para diferentes situações.

## 🏠 Cenário 1: Controle Mensal Pessoal

### Situação

João quer controlar suas despesas mensais pessoais.

### Como Usar

#### Início do Mês

1. **Registre seu salário:**
   - Tipo: Entrada
   - Valor: R$ 5.000,00
   - Descrição: Salário Outubro
   - Método: Transferência
   - Data: 05/10/2024
   - Categoria: Renda

#### Durante o Mês

2. **Registre cada gasto:**

**Segunda-feira:**

```
Almoço no trabalho
- Tipo: Saída
- Valor: R$ 25,00
- Método: Pix
- Categoria: Alimentação
```

**Terça-feira:**

```
Uber para casa
- Tipo: Saída
- Valor: R$ 18,50
- Método: Cartão Santander
- Categoria: Transporte
```

**Quarta-feira:**

```
Supermercado
- Tipo: Saída
- Valor: R$ 285,00
- Método: Cartão Visa
- Categoria: Alimentação
```

#### Fim do Mês

3. **Analise o Dashboard:**
   - Veja quanto gastou no total
   - Identifique qual cartão mais usou
   - Compare com o mês anterior
   - Ajuste gastos se necessário

## 💑 Cenário 2: Finanças de Casal

### Situação

Maria e Pedro dividem as contas e querem organizar as despesas compartilhadas.

### Como Usar

#### Método 1: Conta Única

Ambos usam o mesmo navegador/computador:

- Registram todas as despesas na mesma conta
- Usam **Categorias** para identificar: "Maria", "Pedro", "Compartilhado"
- No fim do mês, filtram por categoria para acertar

#### Método 2: Sistema de Tags

Use a descrição para identificar:

```
Netflix [Compartilhado]
Almoço Maria
Gasolina Pedro
Internet [Compartilhado]
```

Depois, use a busca para encontrar gastos compartilhados.

## 🎯 Cenário 5: Economizando para um Objetivo

### Situação

Carlos quer economizar R$ 10.000 em 10 meses para uma viagem.

### Como Usar

#### Meta Mensal

- Precisa economizar: R$ 1.000/mês
- Estratégia: Reduzir gastos variáveis

#### Monitoramento

**Método 1: Categoria Especial**

```
Criou categoria: "Reserva Viagem"
Toda sobra do mês, registra como:
- Tipo: Saída
- Descrição: Guardado para viagem
- Categoria: Reserva Viagem
```

**Método 2: Conta Mental**

```
No dashboard, observa:
- Se Saldo > R$ 1.000: No caminho certo!
- Se Saldo < R$ 1.000: Precisa economizar mais
```

#### Controle de Gastos Desnecessários

```
❌ Antes de comprar delivery:
- Busca "delivery" no histórico
- Ve quanto já gastou no mês
- Decide se vale a pena

✅ Identifica padrões:
- "Gastei R$ 400 em delivery"
- Próximo mês: Meta de reduzir para R$ 200
```

## 📊 Cenário 6: Análise de Hábitos

### Situação

Lucia quer entender seus hábitos de consumo.

### Como Fazer

#### Semana 1: Registro Detalhado

Registre TUDO, mesmo gastos pequenos:

```
Cafezinho - R$ 3,50
Chiclete - R$ 2,00
Estacionamento - R$ 8,00
```

#### Semana 2-4: Continue Registrando

Mantenha o hábito por pelo menos 1 mês.

#### Análise

Depois de 1 mês, use os filtros:

1. **Por Método de Pagamento:**

   - Filtre "Cartão Visa"
   - Some mentalmente ou veja no dashboard
   - Descoberta: "Gasto R$ 2.000/mês no Visa!"

2. **Por Categoria:**

   - Busque "Alimentação"
   - Descubra: "30% do meu salário vai pra comida"

3. **Por Padrões Temporais:**
   - Ordene por data
   - Identifique: "Gasto mais nos finais de semana"

#### Ação

Com base na análise:

```
Descobriu: Gasta muito em delivery

Ação:
1. Meta: Reduzir delivery pela metade
2. Alternativa: Cozinhar mais em casa
3. Acompanhamento: Verificar no fim do mês
```

## 🏃‍♂️ Cenário 9: Mudança de Hábitos

### Situação

André quer reduzir gastos com aplicativos de comida.

### Como Usar

#### Mês 1: Baseline (Entender o Problema)

- Registre todos os pedidos de delivery
- Não mude nada, apenas observe
- Fim do mês: Some tudo
- Exemplo: "Gastei R$ 720 em delivery!"

#### Mês 2: Definir Meta

- Meta: Reduzir para R$ 360 (50%)
- Estratégia:
  - Cozinhar 3x por semana
  - Marmita 2x por semana
  - Delivery apenas fins de semana

#### Mês 2-4: Acompanhamento

Toda sexta-feira:

1. Filtre por "delivery"
2. Some os gastos da semana
3. Veja se está dentro da meta
4. Ajuste se necessário

#### Resultado

Após 3 meses:

- Compare: Mês 1 vs Mês 3
- Economizou: R$ 360/mês
- Em 1 ano: R$ 4.320 economizados!

## 🎯 Metas Inteligentes

### ❌ Meta Ruim

"Vou gastar menos"

### ✅ Meta Boa

"Vou reduzir gastos com delivery de R$ 720 para R$ 360 no próximo mês"

### Por que é melhor?

- **Específica:** Delivery
- **Mensurável:** De R$ 720 para R$ 360
- **Alcançável:** Redução de 50%
- **Relevante:** Vai fazer diferença no orçamento
- **Temporal:** Próximo mês

## 💡 Truques e Atalhos

### 1. Descrições Padronizadas

```
Sempre use o mesmo nome:
✅ "Uber" (sempre)
❌ "Uber", "uber", "Corrida Uber"
```

### 2. Use Emojis (Opcional)

```
🍔 Restaurante
🚕 Uber
🏠 Aluguel
💊 Farmácia
```

### 3. Método de Pagamento

```
Se pagou com cartão, mas vai pagar depois:
- Use o nome do cartão mesmo assim
- Ajuda a controlar o limite
```

### 4. Data Correta

```
Use sempre a data da compra, não do pagamento:
- Comprou no dia 15? Registre dia 15
- Mesmo que vá pagar só dia 30
```

## 🆘 Problemas Comuns

### "Esqueci de registrar gastos"

**Solução:**

1. Olhe extratos bancários
2. Registre retroativamente
3. Use a data correta de cada compra

### "Tenho gastos pequenos demais"

**Solução:**

- Crie categoria "Pequenos Gastos"
- Some os do dia e registre 1 vez
- Ex: "Pequenos gastos do dia - R$ 15,00"

### "Não sei onde está indo meu dinheiro"

**Solução:**

1. Registre TUDO por 1 mês (mesmo R$ 1,00)
2. Analise o dashboard
3. Identifique os "vilões"
